Converted images

    How it works

    The browser decodes each selected PNG, JPEG, or WebP image and re-encodes it with the Canvas API. Choose a format and quality, then download each converted image. The files are not sent to a server.

    Practical example

    Convert a set of large photos to WebP for web use, or save a WebP image as PNG for an application that needs lossless transparency. JPEG does not support transparency, so transparent areas are filled with white.
