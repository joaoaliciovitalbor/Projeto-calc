Merge PDF Files

Combine several PDF documents into one file, privately in your browser.

For Google Drive or Dropbox, use the device file picker: browse the provider app on mobile or a synced folder on desktop if available. This site does not connect to your cloud account; the selected files stay on this device.

    Use the move buttons to set page order. Your files stay on this device.

    Merge status

    How it works

    Select at least two PDF files. The browser copies their pages into a new document in the selected order and downloads the merged PDF. Files are processed locally and are not uploaded.

    Practical example

    Combine related invoices, reports, or scanned pages into one document before sharing or archiving. Confirm the page order before merging and review the resulting PDF before sending it.
