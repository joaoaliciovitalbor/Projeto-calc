Spreadsheet Converter

Convert Excel, CSV, TSV, and JSON files between common spreadsheet formats.

Files stay in your browser. When an Excel workbook has multiple sheets, the first sheet is converted.

Conversion status

How it works

Select an Excel, CSV, TSV, or JSON file and choose an output format. The file is parsed and converted on your device; no upload is required. Excel workbooks with several sheets use their first worksheet for this conversion.

Practical example

Turn a CSV export into an Excel workbook to continue sorting and editing it, or convert a small JSON array into a spreadsheet for review. Check date and number formatting after conversion because applications can interpret values differently.
