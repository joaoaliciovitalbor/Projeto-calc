Percentage Calculator

Find a percentage of an amount, or apply a percentage increase or decrease.

Calculation result

How it works

The percentage-of option multiplies a base value by the percentage and divides by 100. The increase and decrease options apply that percentage to the base amount and return the adjusted total.

Practical example

For a base value of 200, 15% is 30. Increasing 200 by 15% gives 230; decreasing 200 by 15% gives 170.
