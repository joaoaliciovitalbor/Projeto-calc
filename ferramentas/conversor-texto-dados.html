Text Cleaner and Converter

Remove duplicate lines, change text case, and export content as CSV.

Your data is processed locally in your browser.

How it works

Duplicate removal compares each line after trimming leading and trailing spaces, keeps the first occurrence, and preserves the original order. Case conversion changes all input text. CSV export creates a single-column file and escapes quotes and separators as needed to keep values readable.

Practical example

If a list contains “Ana”, “Bruno”, and “Ana” on separate lines, removing duplicates returns only “Ana” and “Bruno”, in that order. After editing the text, choose “Export CSV” to download the result and open it in a spreadsheet program. Check the encoding and delimiter for your application.
