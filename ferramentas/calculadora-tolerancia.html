Tolerance Calculator

Compare a measured value with the nominal value and allowed tolerances to check compliance.

Inspection result

How it works

The acceptable range is calculated by subtracting the lower tolerance from the nominal value and adding the upper tolerance. A measurement is approved when it falls within these limits, inclusive. Tolerances are absolute values in the same unit as the nominal value; for example, compare millimeters with millimeters.

Practical example

If the nominal value is 10 mm and both tolerances are 0.5 mm, the acceptable range is 9.5 mm to 10.5 mm. A measurement of 10.3 mm is approved; a measurement of 10.6 mm is outside the range. This tool does not replace the inspection criteria defined for each process.
