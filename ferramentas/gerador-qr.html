Create a QR code from a web address, contact details, or any short text.

Generated QR code

How it works

Enter a link or text, choose the output size and error-correction level, then generate a QR code. The code is created in your browser and can be downloaded as a PNG image; the entered content is not uploaded.

Practical example

Create a QR code for a business page, event check-in link, or shared document. Scan the downloaded image with a phone before printing or sharing it to confirm that it opens the intended content.
