Compression status

How it works

Structure-only mode rewrites the PDF without rasterizing pages or intentionally lowering image quality; some PDFs may stay the same size or become larger. Re-saving can invalidate digital signatures or affect advanced PDF features. Visual mode renders each page and rebuilds the document from compressed images. Compare the reported file sizes before using the result.

Practical example

Try structure-only optimization first when you need searchable text and links. If a PDF is still too large to share, visual compression may help; review every page at its intended display size because smaller output can mean softer text and images.
