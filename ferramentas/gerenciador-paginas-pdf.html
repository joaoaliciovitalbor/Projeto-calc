Organize PDF Pages

Reorder, rotate, remove, extract, or split pages without uploading the document.

For Google Drive or Dropbox, use the device file picker and choose a provider app or synced folder if available. This site does not connect to your cloud account.

Enter every page number once, in the new order, separated by commas.

Page numbers start at 1. Saving a modified PDF can invalidate digital signatures or affect advanced document features; keep the original file.

How it works

Select a PDF and choose a page operation. Page ranges use numbers beginning at 1, and comma-separated lists can include ranges such as 2-4, 7. Reordering requires every page number exactly once. The browser processes the document locally and creates a new file for download.

Practical example

Move a cover page to the beginning by entering its page number first, remove blank pages by listing them, or extract a set of pages for a shorter handout. Splitting creates one PDF per page and packages the results in a ZIP file.
