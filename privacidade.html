Who operates this site

Office Utilities is an independent project operated under the public name joaoVS in Brazil. A monitored public contact email has not yet been configured. Add a real contact address to the Contact page before publishing the site or collecting privacy requests.

Information you enter and files

The calculators, text tools, and file tools are designed to process submitted values in your browser. The site does not require an account, and the tool code does not intentionally send your entered values or selected files to an Office Utilities server. Do not enter confidential or sensitive information.

Some tools load libraries from third-party CDNs when needed. The CDN receives the library request and standard connection data; the selected document is processed by the browser and is not attached to that library request.
